# Partial question import and sharing agent instructions
<!-- plan-slug: partial-question-import-and-share-agent-instructions -->

## Goal
When pasting JSON, offer a choice between replacing the whole catalog and adding questions without losing existing data or progress. Place a Share button beside the JSON-generation instruction; it opens the system share sheet with the instruction text.

## Context
- `lib/data/topic_catalog.dart`: `importJson` accepts `version: 1` and a nonempty `topics` list, validates before writing, generates new IDs, replaces user topics, clears additions and edits, and hides built-in questions. `addUserTopic` creates a topic; `addQuestionsToTopic` appends to user and built-in topics.
- `lib/ui/settings_screen.dart`: the original import button calls `importJson` and then `resetProgress`. The instruction is already selectable via `context.l10n.agentJsonInstruction`.
- Progress is tied to question IDs (`lib/ui/training_view_model.dart`). Appending must preserve existing IDs and must not call `resetProgress`.
- RU/EN strings live in `lib/l10n/app_ru.arb` and `lib/l10n/app_en.arb`, generated using Flutter `gen-l10n`. Catalog and settings-screen tests already exist. The system Share dependency was not yet added at the time of planning.
- Built-in topic titles differ between RU and EN even though their IDs match. Matching titles cannot automatically merge translated versions of a topic.

## Scope
- Two explicit actions after pasting JSON: “Replace all” and “Add.”
- Create entirely new topics or append questions to an existing topic whose title matches after trimming and case-insensitive comparison. Repeated imports may duplicate questions.
- Validate the complete JSON before appending; preserve the existing replace-and-reset behavior.
- Share the currently localized instruction on supported platforms.

## Out of Scope
- Matching topics across languages, deduplicating questions, restoring IDs from JSON, or preserving progress after full replacement.
- Changing the `version: 1` schema or exported JSON.

## Validation
- Automated: `flutter analyze`, `flutter test test/data/topic_catalog_test.dart test/ui/settings_screen_test.dart`, then `flutter test`.
- Manual on a device with system Share support: paste JSON with an existing and a new topic, choose “Add,” verify new questions and unchanged prior topics/progress; repeat with “Replace all” and verify reset; check that Share passes the instruction in the selected language. Compilation and widget tests alone do not prove the native share sheet works.

## Acceptance Criteria
- The dialog offers “Replace all” and “Add” after pasting JSON.
- “Add” retains existing topics, questions, edits, and progress; matching titles receive new questions and other titles create topics.
- Invalid JSON leaves catalog and progress unchanged; “Replace all” behaves like the old import.
- Share opens the system sheet with the localized instruction and without user data.
