# Частичный импорт вопросов и отправка инструкции агенту
<!-- plan-slug: partial-question-import-and-share-agent-instructions -->

## Goal
Добавить при вставке JSON выбор между полной заменой каталога и добавлением вопросов без потери существующих данных и прогресса. Рядом с инструкцией для генерации JSON разместить кнопку Share, открывающую системное меню «Поделиться» с текстом инструкции.

## Context
- `lib/data/topic_catalog.dart`: `importJson` принимает `version: 1` и непустой массив `topics`, проверяет данные до записи, генерирует новые ID, заменяет пользовательские темы, очищает дополнения и правки, скрывает встроенные вопросы. `addUserTopic` создаёт тему; `addQuestionsToTopic` дописывает вопросы и в пользовательские, и во встроенные темы.
- `lib/ui/settings_screen.dart`: единственная кнопка импорта вызывает `importJson`, затем `resetProgress`. Инструкция уже отображается через `context.l10n.agentJsonInstruction` как выделяемый текст.
- Прогресс привязан к ID вопросов (`lib/ui/training_view_model.dart`). При добавлении существующие ID должны сохраняться, а `resetProgress` вызываться не должен.
- Строки RU/EN находятся в `lib/l10n/app_ru.arb` и `lib/l10n/app_en.arb`; локализации генерируются Flutter `gen-l10n`. В проекте уже есть тесты каталога и экрана настроек. Зависимости для системного Share пока нет.
- Названия встроенных тем различаются между RU и EN при одинаковых ID. Сопоставление по названию не сможет автоматически объединить переводы одной темы.

## Scope
- Два явных действия в диалоге после вставки JSON: «Заменить всё» и «Добавить».
- Добавление целых новых тем либо вопросов в существующую тему при совпадении названия после `trim` и сравнения без учёта регистра; при повторном добавлении одинаковые вопросы могут дублироваться.
- Проверка всего JSON до начала добавления; существующее поведение полной замены и сброса прогресса сохраняется.
- Кнопка Share для текущего локализованного текста инструкции на поддерживаемых платформах приложения.

## Out of Scope
- Сопоставление тем между разными языками, дедупликация вопросов, восстановление ID из JSON или сохранение прогресса при полной замене.
- Изменение схемы `version: 1` и экспортируемого JSON.

## Acceptance Criteria
- Диалог предлагает «Заменить всё» и «Добавить» после вставки JSON.
- «Добавить» сохраняет существующие темы, вопросы, правки и прогресс; совпадающие по названию темы получают новые вопросы, несовпадающие создаются.
- Невалидный JSON не меняет каталог и прогресс; «Заменить всё» ведёт себя как прежний импорт.
- Share открывает системное меню с локализованной инструкцией для агента, не отправляя пользовательские данные.
