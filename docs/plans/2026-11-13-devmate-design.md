# Devmate — первый релиз

## Цель

Офлайн-подготовка к техническим интервью для Frontend, Flutter, iOS и AI-first разработчиков. Проект создаётся для iOS, Android и Web.

## Сценарий

Каталог содержит десять тем, включая архитектуру, сложность алгоритмов, JavaScript / TypeScript, структуры данных, тестирование и системный дизайн. Пользователь выбирает вопрос, пишет ответ, открывает эталон и самостоятельно оценивает себя. Если ответ был неточным, пользователь повторно формулирует его по памяти. За вопрос начисляются 5 или 10 XP; повторение не увеличивает суммарные очки, но позволяет улучшить оценку. Доступен прогресс по темам.

## Визуальное направление

Тёмная developer-панель: глубокий сине-графитовый фон, светлый текст, лаймовый акцент только для основного действия и прогресса, лавандовый — для тематических пиктограмм. Компактные подписи с увеличенным межбуквенным интервалом сочетаются с крупной типографикой вопроса. На главной первым видно действие «Продолжить тренировку», затем реальная статистика и каталог. На узком экране блоки идут друг под другом, на широком — вступление и прогресс рядом, темы в две колонки. Переходы стандартные, без декоративной анимации.

## Архитектура

Модели вопросов отделены от каталога данных. `ProgressRepository` скрывает локальное хранилище `shared_preferences`; `TrainingViewModel` управляет загрузкой, записью и подсчётом очков. UI содержит каталог, экран темы и тренировку. Вопросы поставляются в приложении, сервер и аккаунт не нужны. Для будущей AI-проверки можно добавить отдельный сервис оценки без изменения каталога.

## Ошибки и проверка

Пустые ответы не проходят дальше. Ошибки локального чтения и записи показываются пользователю; неподтверждённая запись не засчитывается. Тесты проверяют игровой цикл, уникальность вопросов, сохранение результатов и отсутствие накрутки очков. Статический анализ и сборка Web проверяют приложение на этапе разработки.
